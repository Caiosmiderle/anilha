# Teste em celular real

Abra a landing no endereço de prévia da Vercel desta branch (ou, depois do merge, em `/conheca/` do site). Para cada linha: faça o que está em "Faça" e confira "Deve acontecer". Me devolva o número das linhas que falharem, com print.

## Android (Chrome)

| #   | Faça                                                                      | Deve acontecer                                                                                 |
| --- | ------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| A1  | Abra `/conheca/` no Chrome                                                | Vídeo vertical começa sozinho, sem som; botão "Ativar som" no canto                            |
| A2  | Toque em "Ativar som"                                                     | O som liga (ticks e chime); o botão vira "Tirar som"                                           |
| A3  | Role até "Como instalar"                                                  | A aba Android já vem aberta                                                                    |
| A4  | Se aparecer "Instalar o app" ou "Instalar o Anilha", toque                | Abre a janela do Chrome para instalar; confirme; o ícone aparece na tela                       |
| A5  | Sem o botão: menu ⋮ do Chrome                                             | Existe "Instalar app" ou "Adicionar à tela inicial". Me diga qual dos dois nomes aparece       |
| A6  | Durante a instalação                                                      | A janela mostra as telas do app (capturas novas do manifesto)                                  |
| A7  | Abra o Anilha pelo ícone                                                  | Abre em tela cheia, sem barra do navegador; a barra do sistema combina com o tema              |
| A8  | Mande o link de `/conheca/` para você no Instagram (direct) e abra por lá | Aparece o aviso laranja "Você abriu este link dentro de outro app" e o botão "Abrir no Chrome" |
| A9  | Toque em "Abrir no Chrome"                                                | O Chrome abre na mesma página                                                                  |
